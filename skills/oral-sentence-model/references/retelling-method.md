# 复述法 (Retelling Method)

> 提炼自 english/法1.md，作为句模 skill 的练习方法论参考。当用户要求复述练习或涉及"怎么把句模练到脱口而出"时，参考本文档。

## 一、口语学习者的核心弱项

| 弱项 | 具体表现 |
|------|---------|
| 口语结巴 | 开口说不流畅，卡顿频繁 |
| 没有内容 | 想说但不知道说什么，缺乏可调用的表达储备 |
| 被动输入无效 | 看美剧、影子跟读后没有内化，看完就忘，实际对话中调不出来 |
| 中文思维翻译 | 习惯先用中文想好再翻译成英文，表达不地道 |
| 复杂句子看不懂 | 长难句抓不住重点，不知道核心信息在哪 |
| 语音语调不自然 | 缺乏英语的节奏感，影响表达清晰度 |

**句模系统直接解决"没有内容"和"复杂句子看不懂"的问题；复述法解决"被动输入无效"和"中文思维翻译"的问题。两者配合覆盖全部弱项。**

## 二、核心方法：高强度可理解性复述

> **机械跟读（Shadowing）没用** — 最多练到发音肌肉，对语言习得没有意义。关键在于**主动思考 + 主动输入 + 内化为自己的东西**。

### 复述法四步

| 步骤 | 要点 |
|------|------|
| **❶ 记关键词** | 听完一句话后，记住几个关键词，不需要记每个词 |
| **❷ 用自己的话重组** | 立刻用自己的话重新组织表达，尽量贴近原意。这个过程会暴露自己的表达习惯 |
| **❸ 不断向原文靠拢** | 反复听一句话，找到自己的卡点，对比自己和母语者的表达差异，逐步修正 |
| **❹ 高意识输入** | 深刻理解内容，分析母语者的表达方式（用词、句式、连读弱读），而不是机械重复 |

### 一句话总结

> 听完母语者说一句话 → 记住大概意思和关键词 → 马上用自己的话复述出来 → 对比原文修正差距。

雅思口语考试中，面对考官的引导和注视，**最终能脱口而出的只有你真正内化的表达**，不可能是临时准备的模板。

## 三、训练步骤（实操）

1. **听第一遍** — 专注记内容，理解大意
2. **听第二遍** — 补漏 + 尝试跟读，注意自己卡住的地方
3. **复述** — 用自己的话把内容说出来，录音
4. **对比纠正** — 把自己的录音和原音一起放，比较发音、语调、表达方式
5. **找人/工具纠正** — 找 AI 或口语工具帮忙纠正发音和表达（口语一定要有人纠正）

### 适配到句模练习

将上述步骤中的"听"替换为"读句模中的长句"即可：

1. 读第一遍 — 专注理解内容，记住关键词
2. 读第二遍 — 关注词伙在句中的位置和用法，注意自己陌生的表达
3. 复述 — 不看原句，用自己的话复述出来（建议录音）
4. 对比纠正 — 对比自己的复述和原句，从词伙、句型、观点三个维度找差距
5. 找 AI 纠正 — 让 AI 帮忙分析差距，给出改进方向

## 四、素材选择原则

| ✅ 合适的 | ❌ 不合适的 |
|-----------|-------------|
| 真人讲真话（即兴采访、日常闲聊） | 演讲稿、书面语 |
| 自然即兴内容 | 机翻字幕（不地道） |
| 短句为主（日常交流大多用短句） | 美剧中大量长从句 |
| 2 分钟左右的片段（不贪多） | 长时间素材（越痛苦越难坚持） |

**推荐素材**：《走遍美国》、雅思听力原文（英/澳/美式母语者录音）、真人采访片段。

> ⚠️ 雅思听力素材虽地道，但它属于标准化考试口语，和日常闲聊有区别，不能完全划等号。

### 对句模生成的启示

- 句模的句子应尽量贴近"真人说话"的自然感，避免书面语和机翻风格
- 日常话题可以偏短句，不必追求每个句子都又长又复杂
- 每个话题的句模总量控制在 2 分钟可读完，不追求数量

## 五、辅助方法

- **看剧对比法**：看美剧时，着重观察英文和中文字幕，先想"我会怎么表达"，再对比母语者的说法。阻力更小、更容易坚持。
- **保持短句**：日常交流大多用短句，复述时句子拆短，方便自己掌握。

## 六、关键提醒

1. **避开机翻** — 不地道，学了反而有害
2. **不要贪多** — 2 分钟即可，越痛苦学习质量越低，越难坚持
3. **主动思考是关键** — 看剧/跟读后没有主动思考和输入，等于白看
4. **口语一定要有人纠正** — 可以找 AI 或其他工具
5. **修正语音语调** — 语言的节奏感不仅好听，而且能清楚传达内容

## 与句模系统的关系

| 维度 | 句模系统 | 复述法 |
|------|----------|--------|
| 解决的问题 | "说什么" — 提供表达素材 | "怎么说出口" — 内化表达素材 |
| 核心产出 | 6问12句 + 词伙/句型/观点 | 差距分析 + 逐轮改进 |
| 使用时机 | 准备新话题时 | 拿到句模后练习时 |
| 最终目标 | 搭建可复用的语言素材库 | 把素材库变成嘴巴上的本能 |
