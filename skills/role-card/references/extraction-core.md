# 抽取内核（精简版）

> 由影视剧角色抽取规范精简合并而来。影视 + 网文两套方法，共用魅力分析框架（见 templates.md）。
> 原则：只做客观抽取，把角色"是什么样"钉牢；"为什么打动人"归魅力分析，别混在一起。

## 判定依据优先级（高→低，越靠前越可信）

1. **角色亲口台词 / 原文对话**（自我表述、口头禅、价值观发言）
2. **主动做出的选择与行动**（面对危机、利益、亲情、善恶时的取舍）
3. **心理描写**（网文独有：内心独白是直接证据）
4. **他人的评价**（多人一致可信，单人偏见不算）
5. **表演 / 镜头细节**（影视：神态、语气、下意识动作、机位光影配乐）
6. **读者/观众共识**（网文：评论区、书评反复提及的定性）
7. **主创/作者访谈、百科、官方资料**（仅补充，不推翻正片/正文剧情）

**硬性红线：** 无剧情支撑的内心想法一律标注「无明确剧情佐证，不主观脑补」。

## 客观抽取 7 大板块

1. **基础档案**：姓名、年龄区间、职业/身份、家庭背景、角色定位（主角/正派配角/反派/悲情配角/工具人）
2. **人生关键节点**（按时序）：发生了什么 + 这件事如何改变了他的观念与处事方式
3. **性格画像**（全部用行为佐证，拒绝空洞形容词）：
   - 稳定优点 / 性格缺陷、软肋、阴暗面 / 雷区（什么事会失控、心软、妥协）
   - 区分：一时冲动 ≠ 长期稳定性格；偶然一次善意不算固定人设
4. **能力与短板**：谋生技能、社交手腕、思维优势；天生短板、处事盲区
5. **语言 & 行为习惯**：口头禅、说话语调（温和/犀利/内敛/圆滑）、习惯性小动作、待人差异（对家人/下属/敌人完全不同）
6. **人际关系**：亲人、挚友、对手、爱慕对象；纠葛由来
7. **深层内核**：一生想追寻的、内心潜藏的恐惧、做人底线

## 影视抽取要点

- 素材来源：台词、镜头表演、微表情、剧情事件、场景抉择、镜头隐喻；**几乎没有直白内心旁白，必须靠行为倒推性格**。
- 微动作是关键素材：紧张时摩挲手指、开心只嘴角极浅上扬——这些无声细节是判定内敛/自卑/敏感的核心依据。
- 反派极少纯粹坏：抓早年遭遇、信念偏差、行事逻辑、他信奉的正义，不贴"凶狠恶毒"标签。
- 群像剧逐个拆解：先梳理时代大背景，再看时代如何裹挟每个人的选择。

## 网文抽取要点

- 素材来源：心理独白（直接证据）、金句、高光章、章节末读者评论、追读/订阅转折点。
- 心理描写是影视没有的优势：直接把内心动机写穿，抽取时优先采信。
- 读者反馈是重要佐证：评论区反复被夸/被骂的定性能反映角色在读者心中的形象。
- 长篇小说注意弧光分阶段：早期人设 → 中期蜕变 → 后期定型的节点要分开标注。

## 共通避坑

1. 看言行是否一致：嘴上看淡名利、处处钻营 → 内心野心重。
2. 配角戏份少：能抽的内容有限，不强行堆砌性格。
3. 续作、番外、改编人设变动：分开区分，注明版本。
4. 演员本人 / 作者本人 ≠ 角色，严格切割。
5. 不套 AI 通用神态套词（眼底掠过一丝、眸光微动、心头一震等空洞表述）。
