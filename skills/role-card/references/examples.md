## 0. 流程走一遍

1. 输入：作品《狂飙》（影视），角色 高启强
2. 联网查证：百科钉身份履历；知乎/豆瓣捞口碑（"高启强为什么让人同情""有血有肉的反派"）

## 1. 精简角色卡（产出 → vault/characters/高启强.md）

```markdown
# 高启强
作品：狂飙 · 影视（2023）
原型标签：亦正亦邪 / 破碎感反派
一句话人设：一个只求安稳过日的鱼贩，被命运步步推成黑道掌权人，狠辣是他，软肋也是他。
标志性台词："告诉老默，我想吃鱼了。" 【剧情】

## 关键节点
- 菜市场鱼贩被地痞欺压，谨小慎微只求安稳 → 性格底色：隐忍、怕事 【剧情】
- 除夕夜送电视机结识安欣，借警察身份震慑地痞 → 初次尝到权力的好处，心态转向 【剧情】
- 认泰叔做干爹、接手白金瀚 → 彻底踏入灰色地带，做事果决狠辣 【剧情】
- 建工集团掌权，一路扩张 → 权力成为他填补底层自卑的工具 【剧情】
- 结局被绳之以法，弟弟妹妹是他永远放不下的软肋 → 弧光闭环 【剧情】

## 讨喜点 / 情绪机制
- 底层挣扎的真实感，观众想到身边摸爬滚打的人 → 共情 【真实评论】
- 对弟弟妹妹毫无保留的护短，狠人身上唯一的柔软 → 共情 【剧情】
- 能力与野心匹配，从鱼贩到掌权者的"逆袭"路径清晰 → 爽感/向往 【真实评论】

## 反转 / 弧光
- 前期怯懦客气 → 后期沉稳狠辣：不是突然变坏，是每一步都被处境推着走 【剧情】
- 设计手法：每次抉择都给足"被逼无奈"的铺垫，让观众一边恨一边理解 【推断】

## 观众口碑
- 弹幕/知乎反复提"心疼高启强""有血有肉的反派"——反派能引发共情是罕见的成功 【真实评论】

## 可复用配方
- 底层出身+只求安稳却被命运步步推入绝境+全是为了在乎的人 = 破碎感共情 → formulas/共情.md
- 清晰可见的逆袭路径（低起点→掌权）+守护之人作为底线 = 反派也有人味的塑造法 → formulas/爽感.md

## 存疑待确认
- 无（该角色资料充足）
```
