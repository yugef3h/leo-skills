# 模板集

## 依据标注符号（全库统一）

每条判断后缀一个标注：
- `【用户口述】` — 用户本人提供（用户是资深读者，算一级依据）
- `【真实评论】` — 书评/影评/豆瓣/知乎/弹幕/长评里的实际反馈
- `【官方】` — 百科、官方简介、作者/主创访谈
- `【剧情】` — 作品内容本身（台词/情节/心理描写）
- `【推断】` — AI 分析推论，**必须标注**，供用户复核

## 精简角色卡模板

> 写进 `vault/characters/<角色名>.md`。目标：**能扫读、不冗长**。每条判断带依据标注。

```markdown
# <角色名>
作品：<作品> · <影视/网文>
原型标签：<破碎感/亦正亦邪/天才的笨拙/强而柔/苏感/疯批/少年气…>
一句话人设：<这个角色最钩人的核心，一句话，编剧式钩子>
标志性台词：<有则写，没有就删掉这一行>

## 关键节点（3-5 个）
- <事件> → 怎么改变了 TA 【剧情/官方】

## 讨喜点 / 情绪机制
- <讨喜点> → <共情/向往/爽感/遗憾美/投射> → <依据：场景/台词/评论> 【…】

## 反转 / 弧光
- <转折前 → 转折后> + 设计手法 【剧情】

## 观众口碑（有则写）
- <真实评论里反复被提的点> 【真实评论】

## 可复用配方
- <一条可填空公式> → 已归入 formulas/<机制>.md

## 存疑待确认
- <查证不到/不确定处>
```

## 魅力分析六维度

| 维度 | 问什么 | 产出要求 |
|---|---|---|
| 高光节点 | 哪些场景最动人 | 3-5 个，每个一句 |
| 讨喜点 | 为什么让人喜欢 | 必须映射到情绪机制 |
| 反转/弧光 | 转折前后反差 | 前 → 后 + 怎么设计的 |
| 人格魅力源 | 底层是哪类魅力原型 | 打标签，支持跨角色对比 |
| 观众口碑 | 观众反复提什么 | 真实评论摘录，无则跳过 |
| 案例/关键故事 | 每条判断的证据 | 场景/台词/原文一句话 |

## 情绪机制分类（配方的归档维度）

| 机制 | 含义 | 示例 |
|---|---|---|
| 共情 | 破碎感、苦难、身不由己 | 高启强的底层挣扎 |
| 向往 | 强大、苏感、自由、被偏爱 | 实力碾压、隐藏大佬 |
| 爽感 | 打脸、逆袭、守护兑现 | 废物逆袭当众证明 |
| 遗憾美 | BE、意难平 | 白月光之死 |
| 投射 | "我也是TA" | 平凡人的执念 |

一个讨喜点可以命中多个机制，取最强的一个归档。

## 配方卡模板（可填空公式）

> 写进 `vault/formulas/<机制>.md` 的表格行。

```
<可填空公式> | <验证角色> | <适用场景> | <一句话案例>
```

公式写法示例：
- `低起点 + 公认废物标签 + 默默守护某人 + 关键一役当众证明 = 逆袭爽点`
- `绝对实力 + 平时收敛 + 只在护人/绝境时亮底牌 = 向往苏感`
- `圆满前一步崩塌 + 一句来不及说的话 + 观众替角色记住 = 意难平`

规则：公式必须是**能直接填空套用**的句式，不是抽象标签；每条配方必须带一个验证过的角色出处。
