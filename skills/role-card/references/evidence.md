# 联网查证与防幻觉细则

> 本 skill 的硬底线：**据实，不脑补**。查得到的标来源，查不到的标「存疑待确认」，绝不硬编。

## 一、联网查证流程

**第 1 轮：剧情事实**
- 查询：`<作品名> <角色名>` 百科 / 剧情 / 人设 / 介绍
- 优先来源：官方简介、百科、权威粉丝 wiki、剧集/小说官方页
- 目标：钉牢身份、关键节点、台词、结局这些客观事实

**第 2 轮：真实口碑**
- 查询：`<作品名> <角色名>` 书评 / 影评 / 豆瓣 / 知乎 / 弹幕 / 长评
- 也查：`<角色名> 为什么 火/讨喜/意难平` 这类争议向问题，容易捞到读者真实情绪
- 目标：找到「观众反复提及的点」，这是魅力分析的口碑依据

**第 3 轮：精读**
- 用 WebFetch 精读高价值页面（口碑集中的长评、剧情解析），摘录可引用的原话。
- 每摘一条，记下出处性质（真实评论/官方/百科）→ 对应标注意。

**网文特殊性：** 多数网文角色没有百科和权威评论，真实口碑散在评论区/贴吧/书评。查不到是常态，直接走依据分级兜底，不要因为没有权威来源就停止蒸馏。

## 二、依据分级（可信度从高到低）

| 等级 | 来源 | 用法 |
|---|---|---|
| 一级 | 用户口述（用户本人是资深读者） | 直接采信，标注【用户口述】 |
| 二级 | 真实评论 / 官方资料 / 百科 | 采信，标注【真实评论】【官方】 |
| 三级 | 剧情事实（作品内容） | 采信，标注【剧情】 |
| 四级 | AI 推断 | **只作假设，必须标【推断】**，列进「存疑待确认」 |

## 三、防幻觉红线

1. **无依据不写**：任何讨喜点/魅力判断，没有剧情或真实评论支撑，一律不落笔，进「存疑待确认」。
2. **查不到就明说**：宁可"查不到"，不可编造细节、台词、情节。
3. **区分情绪与性格**：一时的冲动 ≠ 稳定性格；偶然一次善意 ≠ 固定人设。
4. **区分人与角色**：演员/作者本人性格 ≠ 角色，严格切割。
5. **版本区分**：续作、番外、改编作品人设变动，分开标注。
6. **不用 AI 套词**：拒绝"眼底掠过一丝""眸光微动"这类空洞神态套话。
7. **AI 已有知识也可能记错**：凭记忆蒸馏时，凡涉及具体台词、具体情节、具体年份，尽量联网核一遍；核不到就标【推断】。

## 四、存疑处理

蒸馏结束时列「存疑待确认」清单，交用户拍板：
- 用户确认 → 补入角色卡，更新依据标注。
- 用户否定 → 删除该条。
- 用户未答 → 保留在清单里，不写进正式档案。
